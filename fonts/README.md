# fonts/

Сюда складываются свои шрифты, загруженные через админку (вкладка «Основные
настройки» → блок «Шрифты» → «Добавить свой шрифт»). Поддерживаемые форматы:
`.ttf`, `.otf`, `.woff`, `.woff2`.

Название шрифта в выпадающих списках — имя файла без расширения
(`Montserrat-Bold.ttf` → `Montserrat-Bold`).

Эту папку можно не трогать руками — файлы сюда кладёт сервер при загрузке
через админку. Но можно и вручную скопировать сюда файл шрифта — он
подхватится при следующем обращении к `GET /api/fonts/list` (не нужен
рестарт сервера).
