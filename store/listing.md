# Текст для магазинов

**Название:** Overdeck

**Краткое описание (до 132 символов):**
Twitch: авто-сбор баллов, смайлы 7TV/BTTV/FFZ, панель смайлов, «Сейчас играет» для Overdeck.

**Полное описание:**
Расширение для стримеров и зрителей Twitch, работает вместе с программой Overdeck, но почти всё доступно и без неё.

• Автосбор баллов канала: сам нажимает зелёный сундучок.
• Смайлы 7TV, BTTV и FFZ в чате Twitch (можно выбрать источники).
• Панель смайлов: отдельная кнопка у строки ввода, клик вставляет смайл.
• «Сейчас играет»: передаёт в Overdeck название и обложку играющего видео или аудио (нужна запущенная программа Overdeck).
• 1080p (бета): запрос плейлиста через твой собственный релей. Результат не гарантирован.

Все функции включаются отдельно во всплывающем окне. Данные никуда не собираются, подробности в политике конфиденциальности.

**Категория:** Социальные сети / Развлечения (Social & Communication)
**Язык:** русский
**Политика конфиденциальности:** https://github.com/starikovnik090909-pixel/overdeck/blob/main/PRIVACY.md

**Обоснование разрешений (если спросят):**
- storage: хранение настроек.
- declarativeNetRequest: правило перенаправления плейлиста на релей пользователя, только если включён «1080p».
- Доступ к сайтам: twitch.tv и gql/usher (баллы, плейлист), 7tv/betterttv/frankerfacez (смайлы), localhost (связь с Overdeck).
- Скрипт на всех сайтах: чтение состояния video/audio для «Сейчас играет».
