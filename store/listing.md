# Текст для магазинов

**Название:** Overdeck

**Краткое описание (до 132 символов):**
Twitch: авто-сбор баллов, смайлы 7TV/BTTV/FFZ, панель смайлов, «Сейчас играет» для Overdeck.

**Полное описание:**
Расширение для стримеров и зрителей Twitch, работает вместе с программой Overdeck, но почти всё доступно и без неё.

• Автосбор баллов канала: сам нажимает зелёный сундучок.
• Смайлы 7TV, BTTV и FFZ в чате Twitch (можно выбрать источники).
• Панель смайлов: отдельная кнопка у строки ввода, клик вставляет смайл.
• «Сейчас играет» (по умолчанию выключено, включаешь сам): передаёт в Overdeck название, исполнителя, обложку, имя сайта и заголовок вкладки играющего видео или аудио (нужна запущенная программа Overdeck).
• 1080p (бета, по умолчанию выключено): запрос плейлиста Twitch через твой собственный релей; релей видит токен воспроизведения, поэтому нужен только свой. Результат не гарантирован.

Все функции включаются отдельно во всплывающем окне. Смайлы: имя и номер просматриваемого канала отправляются сервисам 7TV, BTTV (и FFZ, если включён); картинки грузятся только с их CDN. Данные «Сейчас играет» идут только на localhost, в программу Overdeck на твоём ПК. Ничего не собирается, подробности в политике конфиденциальности.

**Категория:** Социальные сети / Развлечения (Social & Communication)
**Язык:** русский
**Политика конфиденциальности:** https://github.com/starikovnik090909-pixel/overdeck/blob/main/PRIVACY.md

**Обоснование разрешений (если спросят):**
- storage: хранение настроек.
- declarativeNetRequest: правило перенаправления плейлиста на релей пользователя, только если включён «1080p».
- Доступ к сайтам: twitch.tv и gql/usher (баллы, плейлист), api 7tv/betterttv/frankerfacez (списки смайлов), localhost (связь с Overdeck). CDN смайлов в разрешениях не нужен: картинки грузит сама страница.
- Скрипт на всех сайтах: чтение состояния video/audio для «Сейчас играет». Работает только после включения функции пользователем (по умолчанию выключена), слушает события плеера и шлёт данные раз в 3 секунды, пока играет медиа.
