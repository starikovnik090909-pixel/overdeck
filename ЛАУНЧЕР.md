# Overdeck — лаунчер (Overdeck.exe)

`Overdeck.exe` в корне проекта заменяет `start.bat` и `start-silent.vbs`: запускает сервер оверлея в фоне и открывает админку.

## Что в окне
- **Версия** оверлея (берётся из `package.json`) и состояние сервера (работает / запускается / остановлен, порт из `config.json`).
- **Открыть админку** — `http://localhost:<порт>/admin` в браузере.
- **Открыть консоль** — окно с выводом сервера (баннер STARIKOV, ошибки, сообщения чата и т.д.), как при обычном старте. История сохраняется, пока лаунчер запущен.
- **Проверить обновления** — см. ниже. Автоматически проверяет один раз при запуске.
- **Запустить / Остановить сервер**.

Закрытие окна сворачивает лаунчер в трей, сервер продолжает работать. Полностью выйти (и остановить сервер): правый клик по значку в трее → «Выход». Повторный запуск Overdeck.exe при уже работающем лаунчере просто открывает админку.

## Первый запуск
- Нужен Node.js (https://nodejs.org, версия LTS). Если его нет, лаунчер подскажет.
- Если нет папки `node_modules`, лаунчер сам выполнит `npm install` (прогресс — в окне консоли).
- Overdeck.exe должен лежать в корне папки проекта (рядом с `server.js`). Можно сделать ярлык на рабочий стол.

## Проверка обновлений
Нужен адрес, где лежит информация о последней версии. Впиши его в `launcher.json`:
```json
{ "updateUrl": "https://example.com/overdeck-version.json" }
```
Поддерживаются два формата ответа:
1. Свой JSON: `{ "version": "2.1.0", "url": "https://страница-загрузки", "notes": "что нового" }`
2. Последний релиз GitHub: `https://api.github.com/repos/ВЛАДЕЛЕЦ/РЕПО/releases/latest` (версия берётся из тега, ссылка — со страницы релиза).

Пока `updateUrl` пустой, кнопка сообщит, что источник не настроен. Скачивание и установку лаунчер не делает: при новой версии клик по сообщению открывает страницу загрузки.

## Пересборка
Исходник — `launcher/Overdeck.cs`. Двойной клик по `build-launcher.bat` пересоберёт `Overdeck.exe` штатным компилятором Windows (ничего ставить не нужно).
