# Overdeck by Starikov — первый запуск

## 1. Подготовка
1. Скачай архив из раздела **Releases** на GitHub и **распакуй** в обычную папку, например `C:\Overdeck`.
   Не запускай из архива и не клади в OneDrive или на рабочий стол с синхронизацией.
2. Node.js ставить заранее не нужно: если его нет, лаунчер сам предложит скачать (~30 МБ, без прав администратора).

## 2. Запуск (в таком порядке)
1. Открой папку и дважды щёлкни **`Overdeck.exe`**. Больше ничего из папки запускать не надо.
2. Если Windows пишет «Защитник Windows предотвратил запуск», нажми «Подробнее» → «Выполнить в любом случае». Приложение не подписано, это нормально.
3. Если спросит про Node.js, нажми «Да»: он скачается сам.
4. Подожди минуту: при первом старте ставятся зависимости (`npm install`). Ход виден в «Консоль сервера».
5. Админка откроется сама (или кнопка **«Открыть админку»** в окне лаунчера): `http://localhost:3001/admin`.

## 3. Мастер настройки
При первом открытии админки запускается мастер из трёх шагов:
1. **Вход через Twitch.** Нажми «Войти через Twitch»: откроется twitch.tv с кодом, проверь, что он совпадает, и нажми «Активировать». Создавать приложение и вставлять ключи не нужно. После входа Overdeck сам перезапустится с твоим каналом.
2. **OBS.** Скопируй ссылки «Основной оверлей» и «Алерты» и добавь их в OBS (подробнее ниже).
3. **Проверка.** Нажми «Донат» или «Рейд» — алерт должен появиться в OBS.

Уже настраивал Overdeck на другом ПК? В мастере нажми «Открыть файл авторизации».
Свои Client ID и Secret (для разработчиков): вкладка «Подключения» → «Расширенный режим».

## 4. Подключение к OBS
1. Источник → **Браузер**.
2. URL: `http://localhost:3001/overlay.html`
3. Размер: **1920 × 1080**.
4. Сними галочку **«Shutdown source when not visible»**.

## 5. Дальше по желанию
- **Озвучка чата**: вкладка «Озвучка чата», установка движков описана в `ДВИЖКИ-ОЗВУЧКИ.md`.
- **Донаты**: вкладка «Донатный хаб».
- **Чат-бот**: вкладка «Чат бот».
- Закрытие окна лаунчера сворачивает его в трей, сервер продолжает работать. Полностью выйти: значок в трее → «Выход».

## Что есть в папке
| Файл или папка | Для чего |
|---|---|
| `Overdeck.exe` | **запускать только его** |
| `ПЕРВЫЙ-ЗАПУСК.md` | эта инструкция |
| `ЛАУНЧЕР.md`, `ДВИЖКИ-ОЗВУЧКИ.md` | подробности про лаунчер и озвучку |
| `config.json`, `.env` | создаются сами, это твои ключи, никому не показывай |
| `node-runtime` | портативный Node.js, если лаунчер его скачал |
| `launcher.log` | журнал лаунчера, пришли его, если что-то не запустилось |
| остальное | код оверлея, не трогай |

## Если не запускается
- Не открывается админка: закрой старый `Overdeck.exe` и `node.exe` в диспетчере задач и запусти снова.
- Порт 3001 занят: закрой программу, которая его использует.
- OBS на другом компьютере: в `config.json` поставь `"allowLan": true` и перезапусти Overdeck. Виджеты станут доступны по IP этого ПК, а админка всё равно откроется только здесь.
- Ошибка при запуске: пришли файл `launcher.log` и скриншот окна.
